Указатели - адреса ТИПИЗИРОВННЫЕ

Указательный объект
тип * имя пременной
   ^^^---------------- указатель

Что мы умеем с указателями:
  1) получить адрес объекта
  &
  scanf ("%d", &n);
  & === offset

  2) Получить значение по адресу
  косвенная адресация
  РАЗЫМЕНОВАНИЕ УКАЗАТЕЛЯ
  int n = 1;
  int *intP = &n;
  printf("%d", *intP);
              ^^^-------------
              Звездочка перед указательной
              переменной - взятие объекта
              по адресу
  *intP === [intP]

  3) Арифметика с адресами
  ar[4*ecx] === [ar + 4*ecx]
  [esi + 2*edi]
  add esi, 2

  В СИ ТО ЖЕ САМОЕ! Только даже не надо умножать смещение на размер объекта!

  В Си есть информация о размере объекта!
  Поэтому не нужно умножать индекс/номер ячейки в массиве на размер ячейки!

  имя_массива[индекс]
  индекс может быть выражением

  int *intP = ...;
  intP[0]  intP[10]
  intP[2*k - 3*l]

  4) Можно получить размер объекта
  sizeof(тип)
  sizeof(переменная)
    результат - размер в байтах объекта данного данного типа или типа переменной

void MinMax(int len, int *ar,
            int *minVal, int *maxVal) {
  *minVal = 0x7FFFFFFF;
  *maxVal = 0x80000000;

/*
  limits.h

  MAX_INT   MIN_INT
    INT_MAX ????
  MAX_UINT  MIN_UINT
  и т.д.
*/

  int i;
  for (i = 0; i < len; i++) {
    if (*minVal > ar[i])
      *minVal = ar[i];
    if (*maxVal < ar[i])
      *maxVal = ar[i];
  }
}

Динамическая работа с памятью!

Менеджер памяти:
  - учет памяти
  - в многозадачных системах еще и общение с операционкой

1) выделение блока
  void *malloc(unsigned int size);

  void * - нетипизиорованный указатель. Ровно то, что было в ассемблере

  Аргумент - размер желаемого блока
  Результат - указатель на выделенный блок
    или 0 (NULL), если выделение неуспешно

  int *intP = (int *)malloc(40);
              ^^^^^^^----- явно приведение
              типа укзателя

  int n;
  printf("Enter array size: ");
  scanf("%d", &n);
  double *series = (double *)
                     malloc(sizeof(double)*n);

  2) Освободжение блока
  free(указательная переменная)

  Дважды освободить блок - ошибка
  Освободить блок и попытаться использовать - ошибка

  3) Изменение размера блока

  void *realloc(void *pointer,
      unsignaed int new_size);

  Но очень дорогая операция - копирование всего старого блока!
